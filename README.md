# MAT（H）
スワイプで解き方を思い出そう！

## 1. 背景

（未来）大学の前期から後期にまたぐ授業で、後期初めに復習のない授業OR復習が軽い授業で前期の内容を忘れていて、思い出すのがつらい。
例えば解析1の授業→解析2に移って内容を思い出すために時間が必要なのに、
他のことに時間

## 2.対象ユーザ（ペルソナ）

### 瑛太くん（未来大学1年生）
普段はサークルに所属していて、
後期から始まった解析学Ⅱの授業で前期にやった内容を思い出せずにいる。
定期テストの１週間前にテスト対策を初めて余裕なら前日から始める。
課題は普段はAIや友達に聞いたりやらせたりする
宿題は前日にやらせる
テストの当日の正答率は20％

## 3.課題

当日になってAIぶっ込んで理解させることに時間かかったり、
その時の用語を覚えていないことが多い。
（解く時間はない、めんどくてやらない）

テストの問題で、練習の時は何を使って解くかメタ的に解けるからわかるが、
テスト本番だと授業や練習の順番と違ってランダムになるのでわかんなくなる
問題をぱっとみて、何を使ってどのように解くべきかわかりたい。

## 4.目的・方針（提供価値）

数学の解き方を思い出せるか否かをスワイプで判断させて
解けないものについて解説をさせて、復習すべきものを端的にさせる。

## 5.MVP

- スワイプ（解ける・解けない（思い出せない））
- 解説機能
- （扱う勉強範囲は解析学Ⅱの範囲、将来的にはプログラミングとかにもいける）
